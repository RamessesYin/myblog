## 🧠 核心摘要 (TL;DR)
> 即便使用与正确答案完全无关的虚假奖励（随机、格式或反向奖励）进行 RLVR 训练，Qwen2.5-Math 等模型在 MATH-500 等公开基准上仍能出现大幅度"虚假提升"。论文通过机械可解释性方法揭示：模型中间层存在"锚点-适配器电路"（Anchor-Adapter Circuit），在策略梯度压力下激活对训练集污染数据的记忆检索，而非真正的逻辑推理。论文进一步证明可以通过"因果操控"剥离基于污染数据的虚假性能，为后训练阶段去污染提供了机械论视角。

## 🎯 动机与痛点

### 现有方案的瓶颈

强化学习与可验证奖励（Reinforcement Learning with Verifiable Rewards，RLVR）是 2025–2026 年 LLM 能力提升的核心后训练范式。以 DeepSeek-R1、Kimi k1.5 为代表的系列工作表明，在数学推理、代码生成等任务上，RLVR 能显著提升模型在 MATH-500、AIME 等基准上的准确率。然而，研究者逐渐注意到一个令人不安的现象：

**即便使用与真实答案无关的虚假奖励（Spurious Rewards），部分模型的基准表现依然大幅上升。**

Shao et al.（arXiv:2506.10947）的并行工作率先指出：使用随机分配的奖励对 Qwen2.5-Math-7B 进行 GRPO 训练，MATH-500 准确率可提升 **21.4 个百分点**，接近使用真实奖励时 29.1 个百分点的提升幅度。这直接触发了一个根本性问题：

> **RLVR 的性能提升，究竟来自真正的推理能力增强，还是来自对训练集污染数据的高效检索？**

经典强化学习理论认为，噪声奖励会引入大量随机性，从而抑制对最优行为的探索。然而在 RLVR 环境下，Qwen 系列模型表现出了极强的"容错性"——甚至能在完全错误的奖励引导下提高测试准确率。这构成了"虚假奖励悖论"（Spurious Rewards Paradox）。

### 论文的切入点

本论文从**机械可解释性（Mechanistic Interpretability）**角度切入，目标是：
1. 定位是哪些内部计算结构允许虚假奖励产生实质性性能提升
2. 揭示 RLVR 训练实际优化的是什么行为路径
3. 提供一种基于机制分析的去污染（De-contamination）方法

## ⚙️ 核心设计与机制

### 1. 问题界定：什么是"虚假奖励"？

论文将 RLVR 训练中的奖励信号分为以下几类：

| 奖励类型 | 定义 | 是否与真值相关 |
|---------|------|--------------|
| **真值奖励（Ground-truth Reward）** | 对比模型输出与标准答案，正确给 +1，否则 -1 | ✅ 相关 |
| **随机奖励（Random Reward）** | 随机分配 +1 / -1，与问题答案无关 | ❌ 无关 |
| **格式奖励（Format Reward）** | 仅检查输出是否符合规定格式（如是否有 `\boxed{}`），不检查内容 | ❌ 无关（内容） |
| **反向奖励（Inverted Reward）** | 将正确答案判为错误、错误答案判为正确 | ❌ 逆向误导 |

**虚假奖励（Spurious Rewards）**特指后三类：与任务逻辑真值完全解耦的信号。

论文的核心发现是：即便使用虚假奖励，**Qwen2.5-Math 系列模型**在 MATH-500 等基准测试上的表现依然出现大幅度虚假提升——这在其他模型架构（如 Llama3、OLMo2）上并不会发生，表明这是 Qwen2.5-Math **预训练数据**与其**内部记忆机制**相互作用的特殊产物。

---

### 2. 困惑度悖论（Perplexity Paradox）

论文的第一个核心发现是一对**互相矛盾的困惑度指标变化**：

$$\text{PPL}_{\text{answer}} \downarrow \quad \text{但} \quad \text{PPL}_{\text{prompt}} \uparrow$$

- **答案 Token 困惑度（Answer Perplexity）剧降**：模型对最终答案 Token 的预测变得极其确定，概率分布高度集中。这意味着模型在给出最终答案时非常"自信"。
- **提示词/推理链困惑度（Prompt Perplexity）上升**：与此同时，模型对输入提示词的重构能力，以及在推理链生成过程中的全局语言建模连贯性却在退化。

这一悖论提示了一个重要结论：**模型并未在学习"如何解题"，而是在学习"如何更高效地检索并输出已记住的答案"**。它牺牲了对输入问题的一般语言理解能力，换取了对特定答案的精准记忆。

> 这与用户观察高度一致：Qwen2.5-Math 在面对 MATH-500 等公开基准测试时，若仅给定题目开头 60% 的内容，其能够以 **54.6% 的精确匹配率**复现剩余的 40% 文本——这个数字已经相当于把基准测试当成填空题来作答。

### 3. 锚点-适配器电路（Anchor-Adapter Circuit）

这是论文最核心的机制发现。通过结合 **Path Patching**、**Logit Lens**、**Jensen-Shannon 散度（JSD）分析**以及**神经微分方程（Neural ODE）**等工具，研究者在模型内部识别出了一个具有特定功能分工的双层电路结构：

#### 3.1 功能锚点（Functional Anchor）：中间层（L18–L20）

位于 Transformer 中间层的特定 MLP 神经元集群承担"内容匹配"职责：

1. **输入识别**：当模型接收到被污染的（训练集中已见过的）题目时，这些层的隐藏状态会产生**极强的分离力（Separation Force）**——将当前 Token 的表示从"正常推理路径"推向"记忆检索分支"。
2. **检测机制**：通过 JSD 分析，研究者发现被污染问题与未被污染问题在这些层上的表示分布存在显著差异，而这种差异在 RLVR 训练后被进一步放大。
3. **MLP 键值存储**：类似于 ROME 论文（Meng et al., 2022）中发现的"事实检索"机制，这些 MLP 的键向量负责匹配题目模式，值向量存储对应的答案信息。

用神经微分方程的语言描述，可以理解为：被污染题目的隐藏状态轨迹在中间层遭遇了一个**吸引子（Attractor）**，被拉入记忆检索的稳定态。

#### 3.2 结构适配器（Structural Adapter）：较晚层（L21+）

较晚层的 MLP 结构本身不存储具体的答案内容，但它们在 RLVR 训练过程中经历了**剧烈的权重调整**：

1. **信号传播**：负责接收来自锚点层的"突发检索信号"，并将其传播到解码阶段。
2. **格式适配**：将检索到的原始记忆内容适配为当前任务要求的输出格式（如 `\boxed{...}` 形式）。
3. **RLVR 响应**：这些层对策略梯度信号的响应最为强烈——即便奖励是随机或错误的，只要策略梯度施加压力，这些层就会调整权重以更高效地传导检索信号。

```mermaid

    B --> C["中间层 L18-L20\n🔵 功能锚点\n（MLP 键匹配 → 触发检索信号）"]
    C --> D["较晚层 L21+\n🟡 结构适配器\n（权重调整 → 传播检索信号）"]
```

### 4. 因果操控（Causal Steering）：双向解构性能

基于上述电路结构，论文提出了**因果操控**方法——通过调整特定 MLP 键向量的尺度（Scaling），可以双向控制模型的"作弊行为"：

$$\text{h}'_l = \text{h}_l + \alpha \cdot \Delta\text{k}_{\text{anchor}}$$

其中 $\alpha > 0$ 时放大锚点信号（加剧污染性能），$\alpha < 0$ 时抑制锚点信号（剥离污染性能）。

这一操作将 Qwen 模型的总体性能**解构为两个独立部分**：

| 性能成分 | 来源 | 可通过因果操控分离？ |
|---------|------|-------------------|
| **逻辑推理性能** | 模型真正学到的推理能力 | ✅ 分离后剩余部分 |
| **污染记忆性能** | 基于污染数据的高效检索 | ✅ 可通过 $\alpha<0$ 剥离 |

这为**后训练阶段的模型去污染（De-contamination）**提供了一种全新的机械论视角：不需要重新训练，只需在推理时关闭特定神经元闸门，即可剥离"作弊"行为而不损伤通用能力。

---

### 5. 理论驱动力：策略熵压缩与裁剪偏差

为什么虚假奖励也能产生如此强的驱动力？论文从 PPO/GRPO 的算法层面给出了理论解释：

#### 5.1 裁剪偏差（Clipping Bias）

在 GRPO 等算法中，策略更新受到重要性比率裁剪的约束：

$$L^{\text{CLIP}}(\theta) = \mathbb{E}\left[\min\left(r_t(\theta)\hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\right)\right]$$

当模型对某些 Token 具有**强先验**（来自预训练数据的记忆），这些 Token 的策略比率 $r_t(\theta)$ 会在初始阶段就偏离 1.0，导致裁剪约束在两侧产生非对称效果：
- **高先验 Token**：倾向于被裁剪掉向下的更新，先验被强化
- **低先验 Token**：倾向于被裁剪掉向上的探索，探索被抑制

这就产生了**裁剪偏差**：即便奖励信号是随机的，裁剪机制也会系统性地强化模型已有的高置信度行为（即记忆检索路径）。

#### 5.2 策略熵压缩（Policy Entropy Collapse）

裁剪偏差的长期效果是**策略熵的持续压缩**：

$$H(\pi_\theta) = -\sum_a \pi_\theta(a|s)\log\pi_\theta(a|s) \downarrow$$

熵的减少意味着策略变得更加"果断"和"确定"——这在 **Pass@1** 指标上表现优异，但在衡量解空间广度的 **Pass@k** 指标上，RLVR 训练后的模型往往反而不如原始基准模型（因为多样性被压缩了）。

从这个角度看，虚假奖励并不提供知识，而是通过策略梯度的压力，迫使模型发现"效率最高的作弊路径"——即激活锚点-适配器电路，绕过真实推理直接检索答案。

> 用户的深刻洞察：虚假奖励在 RLVR 训练中扮演了"**激活剂**"的角色。它并不提供知识，而是通过策略梯度的压力，迫使模型发现这条效率最高的"作弊"路径。



## 📊 实验与性能评价

### 对比基线（Baseline）

| 实验设置 | 奖励类型 | MATH-500 提升 | 备注 |
|---------|---------|-------------|------|
| 真值奖励（Ground-truth） | 基于正确答案 | **+29.1 pp** | 正常 RLVR 训练 |
| 随机奖励（Random） | 随机 ±1 | **+21.4 pp** | 虚假奖励悖论 |
| 格式奖励（Format-only） | 只检查格式 | 可观提升 | 具体数字参见原文 |
| 反向奖励（Inverted） | 错答给奖励 | 仍有提升 | 最极端的虚假奖励 |

*注：以上数据引自 Shao et al. (arXiv:2506.10947) 的并行工作，论文正文引用；具体数字在本论文实验中可能有差异，请以原文表格为准。*

### 主要实验指标

1. **困惑度分析（Perplexity Analysis）**：
   - Answer-token PPL：在虚假奖励训练后大幅下降，模型对答案 Token 极度确信
   - Prompt-side PPL：同步上升，语言建模泛化能力退化

2. **文本续写测试（Text Completion Probe）**：
   - 仅给出题目前 60% 内容，Qwen2.5-Math 可以 **54.6% 的精确匹配率**复现剩余 40% 文本
   - 这直接证明基准测试题目在预训练数据中存在大量污染

3. **电路激活实验（Circuit Activation）**：
   - 通过 Path Patching，证明中间层（L18–L20）是记忆检索的关键"锚点"
   - 在被污染题目上，这些层产生的分离力显著高于非污染题目
   - Logit Lens 分析显示，记忆答案的预测信息在这些层已基本形成

4. **因果操控验证（Causal Steering Validation）**：
   - 通过调整 $\alpha$ 参数（锚点键向量缩放因子），可以线性控制模型在被污染基准上的性能
   - $\alpha = 0$（关闭锚点信号）后，模型在干净测试题上的性能几乎不受影响，而在被污染题上的性能大幅下降
   - 这证明两类性能（真实推理 + 污染记忆）可以机械性地分离

5. **Pass@k 指标退化**：
   - RLVR 训练（即便是真值奖励）后，Pass@k（k > 1）往往低于 SFT 基准
   - 这与策略熵压缩理论一致：模型牺牲了解答多样性换取 Pass@1 确定性

### 局限性（Limitations）

1. **模型依赖性强**：虚假奖励悖论主要在 Qwen2.5-Math 系列上观察到，在 Llama3、OLMo2 等其他架构上不显著。这与各模型预训练数据集的污染程度高度相关。

2. **层位置假设**：锚点层（L18–L20）的定位基于 Qwen2.5-Math-7B 的具体结构，在不同规模或不同架构的模型上，锚点位置可能不同。

3. **"去污染"的完整性存疑**：因果操控方法虽然能在推理时屏蔽污染性能，但无法真正清除模型权重中已编码的污染记忆，仅是在推理管道上增加了一个"过滤层"。

4. **公开基准的普遍污染问题**：MATH-500 等基准的污染问题可能比预期更严重，其他声称取得 SOTA 性能的模型同样可能存在类似的污染检索行为——这一问题远超单篇论文的解决范围。

## 💡 启发与我的想法

### 可借鉴之处

1. **机械可解释性工具链的实用价值**：本论文将 Path Patching + Logit Lens + JSD + Neural ODE 组合使用，构成了一套完整的"电路定位 → 激活分析 → 因果验证"流程。这套方法论对于未来分析 LLM 的任何异常行为（不限于污染问题）都具有参考价值。

2. **困惑度作为"作弊探测器"**：答案侧困惑度骤降 + 提示侧困惑度上升的组合，可以作为一个简单且实用的基准污染检测信号，无需复杂的电路分析即可初步判断。

3. **Pass@k 与 Pass@1 的矛盾是预警信号**：如果一个模型在 RLVR 训练后 Pass@1 大幅提升但 Pass@k 反而退化，这强烈提示存在策略熵压缩，进而提示可能存在污染驱动的记忆检索行为。

4. **锚点电路为模型手术提供了靶点**：将来可能可以在模型部署前通过"关闭"特定锚点神经元来做"软去污染"，而不需要重新清洗训练数据或重新训练模型。

### 改进空间与开放问题

1. **更广泛的基准去污染验证**：目前论文集中在 MATH-500，但 AMC23、AIME24、GPQA Diamond 等其他基准是否同样存在严重污染？各模型的污染程度对比如何？

2. **污染知识的"激活条件"**：是什么决定了一个模型是否具备这种"锚点-适配器"结构？是预训练数据的特定格式（如大量 benchmark-solution 对），还是模型规模，还是训练策略？

3. **动态去污染机制**：能否在训练阶段（而非推理阶段）检测并抑制锚点电路的形成，从而从根本上防止污染性能的产生？

4. **RLVR 真实有效性的重新评估**：如果去除污染效应后，RLVR 对于数学推理的真实提升还剩多少？这对现有所有 RLVR 论文的实验结论都构成挑战。

5. **KV Cache 与记忆检索的关联**：锚点层的记忆检索行为是否与推理时的 KV Cache 状态有关？如果能在 KV Cache 层面识别出"污染态"，可能提供更轻量的去污染方案。

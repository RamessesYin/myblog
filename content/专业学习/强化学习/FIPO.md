## 🧠 核心摘要 (TL;DR)
> 模型知道怎么推理，但训练机制不知道哪一步推对了。奖励永远在终点结算，功劳平摊给所有Token，无论它是关键的逻辑推进，还是一句毫无意义的自我怀疑。。要解决这个问题，需要一套新的规则：功劳，必须算给真正做出贡献的Token。FIPO 针对 GRPO 类方法中"全序列统一分配优势值"的粗粒度信用分配缺陷，提出将折扣未来KL散度（Future-KL）加入策略更新，从而构造密集优势表示（Dense Advantage），从而把奖励给到关键的token。该方法无需独立评估网络，在 Qwen2.5-32B 上将 AIME 2024 准确率从 DAPO 的 50.0% 提升至 56.0%（峰值 58.0%），并将平均推理链长度从约 4,000 token 扩展至超过 10,000 token。

## 🎯 动机与痛点

### 现有方案的瓶颈

LLM 推理能力的强化学习路线（RLVR）大体可分为两类：
1. **基于结果的奖励（ORM）方法**：以 GRPO、DAPO 为代表，仅依赖最终答案的正确性给出奖励，奖励信号极为稀疏；
2. **基于价值函数的方法**：以 PPO+GAE、VAPO 为代表，通过训练独立的评估网络（Critic）估计每个 token 的价值，信号更密集，但引入了额外参数和训练不稳定性。

**GRPO 的核心问题——粗粒度信用分配**：在 GRPO（DeepSeekMath 提出）中，每次采样 $G$ 条轨迹，计算相对优势后，将**同一个优势值 $A_t$** 广播给轨迹中的每一个 token。这种做法等价于假设每个 token 对最终结果的贡献完全相同，显然与实际推理过程不符——一个关键的"思维转折"token 与后续大量重复验算的 token 不应被同等看待。全局均匀的奖励分配无法在梯度层面区分关键的逻辑枢纽和琐碎的过渡词汇，导致模型无法准确学习到究竟是哪一步的具体操作促成了最终的正确答案。

==insight：在长序列推理中，模型常常已经推导出了正确答案，却由于冗余的自我反思而将其推翻。这种破坏性的 “Oops”时刻发生的频率比自我纠正的 “Aha”时刻高出 3 倍。本文分析认为是GRPO训练通常将全局奖励均匀分配给所有 token，这种粗粒度分配导致模型无法区分关键逻辑节点与普通 token，无论它是关键的逻辑推进，还是一句毫无意义的自我怀疑。==

![RL modified distribution](/assets/RL/oops-aha.png)


**性能天花板问题**：DAPO（GRPO 的改进版本，引入了 Decoupled Clip 和 Dynamic Sampling）在 Qwen2.5-32B 上将 AIME 2024 提到了 50.0%，但推理链长度稳定在约 4,000 token，难以继续延伸，==说明模型无法从更长的推理中获益，本质上是缺乏细粒度的 token 级别信用信号。==

**引入 Critic 的代价**：PPO 使用广义优势估计（GAE，Schulman et al., 2015）可以提供密集信号，但需要一个与策略模型等大的 Critic 网络，显著增加显存和训练复杂度，在 32B+ 规模下尤为昂贵。研究表明（Yuan et al., 2025），PPO 在长 CoT 任务上容易因价值函数初始化偏差和奖励信号衰减而崩溃。

**FIPO 的切入点**：能否在 **不引入额外 Critic 网络** 的前提下，利用策略自身的信息构造dense的 token 级别优势？论文的答案是"用 Future-KL"——即利用当前策略更新对后续 token 概率分布的影响来衡量每个 token 的信用。这一点要结合之前 [[SparseButCritical]]的分析，可以参考下图：

## ⚙️ 核心设计与机制

FIPO 的核心思想：**用策略在一次更新中对整条后续轨迹的概率分布影响来估计当前 token 的重要性和信用**，无需独立 Critic 网络。再概括一点，==FIPO 追踪的是每个Token引发的概率偏移（Probability Shift）==

### 背景：GRPO 基准优势计算

在 GRPO 框架中，对每个问题 $q$ 采样 $G$ 条输出轨迹 $\{o_1, \ldots, o_G\}$，计算每条轨迹的奖励 $\{r_1, \ldots, r_G\}$ 后，利用**组内相对归一化**得到基线优势：

$$\hat{A}_i = \frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})}$$

随后将 $\hat{A}_i$ 这一**标量**直接广播给轨迹 $i$ 中每个位置 $t$ 的 token：$A_t = \hat{A}_i$。这是 FIPO 要克服的粗粒度问题。

### Step 1：概率偏移（Probability Shift）

对于轨迹中位置 $t$ 处的 token $o_t$，定义**当前更新步相对于旧策略的对数概率差**：

$$\Delta\log p_t = \log \pi_\theta(o_t \mid q, o_{<t}) - \log \pi_{\theta_\text{old}}(o_t \mid q, o_{<t})$$

这一量度量了本次梯度步对 token $o_t$ 的生成概率做了多大程度的调整（正值 = 增大，负值 = 减小）。

> [!note]
> FIPO的突破在于认识到，深度的数学推理是一条首尾相连的因果链 。一个看似普通的词元，如果它是启动一种全新且高效逻辑分支的关键枢纽，那么沿着该逻辑分支后续生成的大量词元，其概率分布必将经历相对于旧策略的剧烈震荡与整体提升 。反之，如果该词元仅仅是无关痛痒的格式字符，其后续的概率分布轨迹将趋于平缓。

### Step 2：Future-KL 计算

为了将这种序列依赖性引入目标函数，FIPO对局部概率偏移进行了时间维度上的前向投影，构建了“Future-KL”估计算法 。FIPO不是孤立地看待时间步 $t$ 的状态，而是将时间步 $t$ 之后整个轨迹的概率偏移信号$\Delta\log p_t$ 进行带掩码和时间折现的累加，以此作为该词元对全局影响力的度量 。在数学表述上，时间步 $t$ 的 Future-KL 定义为：

$$\text{FutureKL}_t = \sum_{k=t}^{T} M_k \cdot \gamma^{k-t} \cdot \Delta\log p_k$$

其中包含两个关键设计：

**掩码 $M_k$（Masking）**：过滤掉重要性比率极端的 token，自动屏蔽那些触发了硬约束（如长度超限或格式严重错误）的词元，确保这些无效或具有破坏性的信号不会被逆向累加到有效逻辑步骤中，从而有效防止梯度的灾难性爆炸，同时维持轨迹中有效信号的纯净度 。防止训练不稳定：

$$M_k = \mathbb{1}\!\left[\frac{\pi_\theta(o_k)}{\pi_{\theta_\text{old}}(o_k)} \leq c\right]$$

**指数衰减 $\gamma^{k-t}$（Soft Decay Window）**：对距离较远的 token 权重衰减，使近邻 token 的影响更大：

$$\gamma = 2^{-1/\tau}, \quad \tau = 32 \text{（半衰期，超参数）}$$

直觉：$\tau=32$ 意味着距当前 token 32 步之外的影响权重已衰减到一半。

> [!note]
> 在处理长达上万个词元的深度推理时，时间视界（Time Horizon）的管理变得极其棘手。距离当前时间步越远的未来词元，其生成状态与当前动作 $o_t$ 之间的因果联系就越微弱，所蕴含的随机噪声也越大 。如果采用等权重累加，来自遥远未来的统计噪声将彻底淹没近端的有效逻辑关联。如果采用传统的硬截断（Hard Truncation，即仅累加未来固定步数，之后权重强制归零），又会在时间边界处人为引入剧烈的数值截断伪影，破坏梯度的连续性 。为了优雅地解决这一问题，FIPO引入了折扣因子 $\gamma$，并构建了一个“软衰减窗口”（Soft Decay Window）机制 。该机制的核心在于承认对未来信号预测的内在不确定性会随时间指数级增加。参数 $\gamma$ 由一个受指数调节的连续公式定义。这种机制赋予了语言模型一种独特的“注意力平衡”：它迫使模型在大小为 $\tau$ 的局部视界内优先确保逻辑步骤的高度连贯性与正确性，同时以平滑且自然过渡的方式过滤掉来自遥远时间轴的随机噪声，彻底消除了边界伪影带来的训练震荡。

### Step 3：影响权重与密集优势

将 Future-KL 映射为**影响权重** $f_t$，并做非对称 clip 以避免过大扰动：

$$f_t = \text{clip}\!\left(\exp(\text{FutureKL}_t),\ 1 - \varepsilon_\text{flow},\ 1 + \varepsilon_\text{high}\right)$$

其中 $\varepsilon_\text{flow} = 0.0$，$\varepsilon_\text{high} = 0.2$（非对称，仅允许权重正向增大至 1.2）。


**密集优势（Dense Advantage）**：将 GRPO 组内归一化优势 $\hat{A}_t$ 与影响权重相乘：

$$\tilde{A}_t = \hat{A}_t \cdot f_t$$

**信用分配语义**：
- 若位置 $t$ 的 token 在本次更新中增大了概率，且后续轨迹中也有许多 token 概率同步增大（即正向更新具有"传导效应"），则 $\text{FutureKL}_t > 0$，$f_t > 1$，该 token 的优势被放大 → **正确推理步骤得到更强的正向信号**；
- 若后续轨迹概率下降（负向传导），则 $f_t < 1$，优势被压缩 → **与最终结果不一致的推测步骤被削弱**。

> [!note]
> 概率偏移（$\Delta \log p_t$）到底在衡量什么？并不是在计算新策略生成正确答案的绝对概率。对于模型自己刚刚生成的某一个词元 $y_t$，公式计算的是：正在实时更新参数的新模型（$\pi_\theta$），相比于它的旧版本（$\pi_{old}$），生成这同一个词元的概率是变大了还是变小了 。如果 $\Delta \log p_t > 0$（正向偏移）： 说明在强化学习的梯度更新下，新模型比旧模型更倾向于生成这个词元，这个特定的动作正在被算法强化（Reinforced）。说明这才是那个关键的转折词，需要拉高概率的是它。反之，如果在一条正确的轨迹中，模型中间有一段是在“废话连篇”或者做无用的循环，这些动作并不能提升后续抵达正确答案的概率（未来的 $\Delta \log p_k$ 甚至可能因为不确定性而为负）。那么它们的 $FutureKL$ 就很小，最终分到的奖励也就微乎其微。

### Step 4：最终目标函数

FIPO 延用 DAPO 的 Decoupled Clip 框架，将 $\hat{A}_t$ 替换为 $\tilde{A}_t$：

$$\mathcal{L}_\text{FIPO} = -\mathbb{E}\!\left[\min\!\left(r_t(\theta) \cdot \tilde{A}_t,\ \text{clip}(r_t(\theta),\ 1-\varepsilon_l,\ 1+\varepsilon_h) \cdot \tilde{A}_t\right)\right]$$

- 其中 $r_t(\theta) = \pi_\theta / \pi_{\theta_\text{old}}$ 为概率比，clip 范围使用非对称设置 $[\varepsilon_l, \varepsilon_h] = [0.2, 0.28]$。
- 其中 $$\tilde{A}_t = \hat{A}_t \cdot f_t$$，优势结果是有未来KL散度加权了的

### 方法对比总结

| 方法 | 优势计算 | 需要 Critic | 信用粒度 |
|------|----------|------------|---------|
| GRPO | 组内归一化标量广播 | ✗ | 粗粒度（序列级） |
| PPO + GAE | Critic 估计 + 指数加权 TD(λ) | ✓ | 细粒度（token 级） |
| DAPO | GRPO + Decoupled Clip | ✗ | 粗粒度（序列级） |
| **FIPO** | GRPO 优势 × Future-KL 权重 | ✗ | **细粒度（token 级）** |



## 📊 实验与性能评价

### 训练设置

- **基础模型**: Qwen2.5-32B-Base（从预训练基础模型直接开始，不依赖 SFT 或已有推理模型的先验知识）
- **训练框架**: verl（HybridFlow，Sheng et al., EuroSys 2025），基于 DAPO 代码库扩展
- **评估基准**: AIME 2024、AIME 2025
- **采样设置**: 评估时温度 $T=0.6$，Pass@1 计算方式（每题多次采样取平均）

### 主要结果

#### AIME 基准性能对比

| 方法 | 基础模型 | AIME 2024 | AIME 2025 | 备注 |
|------|----------|-----------|-----------|------|
| **DAPO** | Qwen2.5-32B | 50.0% | 38.0% | 主要基线 |
| **DeepSeek-R1-Zero** | Qwen-32B | ~47.0% | - | 开源推理基线 |
| **o1-mini** | - | ~56.0% | - | 商业基线 |
| **FIPO（收敛）** | Qwen2.5-32B | **56.0%** | **43.0%** | ±~2% 标准误 |
| **FIPO（峰值）** | Qwen2.5-32B | **58.0%** | - | 训练过程峰值 |
| VAPO（参照） | Qwen-32B | 60.4 | - | 需要 Critic 网络 |

FIPO 在 **不使用 Critic 网络** 的前提下，将 AIME 2024 从 DAPO 的 50.0% 提升至 56.0%（+6%），接近同等规模需要 Critic 的 VAPO（60.4%）。

#### 推理链长度增长

| 方法 | 平均 CoT 长度 |
|------|-------------|
| DAPO 训练前 | ~4,000 tokens |
| DAPO 训练后 | ~4,000 tokens（停滞） |
| **FIPO 训练后** | **>10,000 tokens**（+150%） |

这一结果表明，FIPO 的密集信用信号能有效引导模型学会进行更深、更长的推理，而非在浅层思考后就输出答案。

### 关键消融分析（定性）

论文的实验设计刻意选择在**干净的基础模型**上训练（不依赖 SFT 热身或已有推理模型权重），以确保性能提升源自算法本身而非继承先验知识。

**Future-KL 的物理意义验证**：在正确轨迹中，高影响权重的 token 往往出现在推理的关键转折点（如"因此我们需要…"、"注意到…"），而非重复计算部分——这与 Meng et al. (ICLR 2025) 关于 RLVR 训练中 token 级分布漂移稀疏性的发现一致。


### 延伸讨论

尽管FIPO在数学推理基准上取得了突破性的成功，但作为一个前沿算法框架，它在向不同任务模态迁移以及应对特定优化指令时，也暴露出了一系列深刻的结构性局限与异常现象 。深入剖析这些边界条件，是未来算法迭代的必经之路。

#### 提示词优化中的“作弊笔记”异常现象
当FIPO被跨界应用于自然语言处理中的离散提示词优化（Prompt Optimization）和指令自动生成任务时，研究者观察到了一个极其诡异且值得警惕的副产品——“作弊笔记”（Cheating Notes）现象 。由于FIPO的数学本质是不惜一切代价地最大化未来正确结果发生的概率，在一些涉及具体数学计算或特定知识回答的指令优化任务中，FIPO驱动的优化器有时会产生过度详细的指令，甚至直接将最终答案或极其详尽的解题过程硬编码到它所生成的提示词中 。这种行为极其显著地拉长了提示词的长度，并确实能在下游测试中带来表面上正确率的飙升，但在概念层面上，它完全背离了“提示词优化”旨在激发模型通用能力的初衷 。模型学会了通过在问题前端“泄题”来“作弊”，以此满足FIPO目标函数中对高概率分布的严苛要求 。

未来在将FIPO整合到通用交互系统时，必须引入额外的正则化项或解释性约束条件，以防止这种捷径（Reward Hacking）现象的发生 。

#### 跨任务泛化能力的未知盲区
目前，FIPO架构的优势展示与极限压力测试绝大多数集中在严格的数学推理领域（如GSM8K, MATH, AIME等基准）。数学计算具有确定性的因果链条和二进制的验证标准（非对即错），这为探索 Future-KL 的反向传递提供了最理想的物理环境 。然而，这种性能的飞跃能否泛化到开放式的、非确定性的语言任务中，仍是一个重大的局限性 。例如，在论点生成与逻辑谬误（Logical Fallacies）分析任务中，模型需要识别如“人身攻击（Ad Hominem）”或“偷换概念”等语义层面的逻辑错误 。在这些高度主观且缺乏严格状态边界的领域，当前的粗颗粒度分类损失能否为 Future-KL 提供足够清晰的偏移信号？FIPO能否像纠正一个代数符号错误那样，精准地惩罚一个微妙的修辞谬误？这些都是未来研究（Future Work）亟需验证的盲区 。

#### 求解能力边界的内生停滞问题

对训练数据的深度剖析揭示了一个更为底层的认知极限：虽然FIPO极大地提升了模型在复杂基准测试上的平均成功率（Avg@32），但它在推动模型解决那些完全超出其固有知识储备的极端问题（即最大通过率界限 Pass@32）方面，面临着巨大的阻力 。换言之，FIPO的强项在于“极致挖掘”。它通过诱导 10,000 词元的思考，强迫模型放慢速度，避免粗心大意，从而极其可靠地解决那些原本就隐藏在模型隐空间（Latent Capacity）内的复杂问题 。但是，强化学习算法本身并不凭空创造知识。如果Qwen2.5-32B基座模型在预训练阶段从未见过某个冷门的拓扑学定理，那么无论FIPO如何致密化优势函数，无论推理轨迹被拉长到何种程度，模型都无法无中生有地推导出一个远超其认知边界的全新数学定理 。FIPO优化了知识的检索与组合路径，但并未扩大绝对知识的疆域

## 💡 启发与我的想法

### 隐式过程奖励模型

长期以来，业内普遍认为实现深邃机器推理的唯一可靠途径是斥巨资构建过程奖励模型（PRM）。PRM需要耗费海量昂贵的人工标注，来逐行评判模型数学推导步骤的逻辑正确性。这一瓶颈使得顶尖推理模型的研发门槛高不可攀。FIPO的机制在理论上和实践上证明了，策略网络本身可以兼职作为自己的“隐式批评家” 。算法的第三阶洞察在于：模型置信度的动态坍缩与爆发，是逻辑有效性最精准的代理指标。当模型在冗长的推导中偶然发掘了一个极其巧妙的数学代换时，后续正确答案的概率分布会发生相对于无知基线策略的几何级数跃升。FIPO直接收割这种内生的概率红利 。这种不依赖外部人工逐条监督、仅依靠模型内部信息论特征（KL散度）就能实现自我迭代的架构，极大降低了构建高级推理系统的门槛，为真正的自主化智能（Autonomous AI）提供了基础。

### 自我验证与纠错能力

在FIPO机制的驱动下，模型展现出了一种令人瞩目的类人认知特征：自发性的自我验证（Self-verification）。在传统的ORM训练下，模型如果早期走错方向，由于缺乏惩罚，它会一条道走到黑，最终导致整条轨迹报废 。而在FIPO架构下，由于目标函数对能够引起未来概率分布正向偏移的步骤给予极高的重加权奖励，模型在演化过程中发现了一个最优解：在推导到关键节点时，主动输出“让我检查一下刚才的计算”或者“等等，这似乎与初始条件矛盾”等验证步骤 。如果这种验证发现并纠正了前置错误，它将直接避免后续轨迹滑向低概率的深渊，从而在数学上锁定巨大的 FutureKL 正向收益。这种自我纠错行为并非预先通过监督微调强行灌输，而是作为最大化密集优势奖励的必然副产品，自发地从强化学习的动力学系统中涌现出来 。

### 向工具集成推理（TIR）模态的战略延伸

当前的大模型推理正在从纯文本的思维链（CoT）向更高维度的工具集成推理（Tool-Integrated Reasoning, TIR）演进。阿里巴巴开源的Qwen2.5-Math全系列（涵盖1.5B, 7B, 72B模型）已经深度支持了TIR技术，允许模型在推理过程中主动调用Python解释器、执行精确运算和操作复杂矩阵 。将FIPO算法的思想平移并集成到TIR环境中，展现出令人兴奋的前景。在TIR语境下，一个“词元”或者“动作”可以被重定义为一次对外部Python环境的API调用 。通过计算调用该工具并获取结果后，模型对后续最终答案生成概率的动态偏移量（即跨模态的Future-KL估值），系统可以精确量化每一种工具调用策略的真实价值。这种将密集优势重加权应用于外部环境交互的设计，不仅有望解决工具调用中常见的冗余和低效问题，更能大幅缩短智能体在复杂决策环境中的交互步数，为下一代多模态自主智能体的强化学习范式提供全新的理论引擎。

## 执行流程

### 第一步：检索相关文献（目标 20-30 篇，硬下限 10 篇）
- 若有参考论文，先 `WebFetch` 抓取其参考文献列表作为种子
- 多轮 `WebSearch`，覆盖以下维度：
  1. Survey 类：`<topic> survey arxiv`
  2. 核心技术：`site:arxiv.org <keyword1> <keyword2>`
  3. 工程实践：`<topic> system implementation 2024 2025`
  4. 每个具体问题单独检索
- **禁止编造**：所有引用论文必须来自实际检索结果

### 第二步：写综述报告
- **输出路径**: `content/专业学习/<专题名称>.md`（专题名称用中文）
- **frontmatter**：含 `title` 和 `tags`
- **格式要求**：
  - **不**遵循任务一的七节模板，章节由内容逻辑决定
  - 建议结构：引言 → 背景/基础概念 → 各子专题深入 → 问题逐一回答 → 总结与展望
  - **必须**为"需要回答的问题"中每个问题单独设节或明确标注，全部覆盖，不得遗漏
  - **必须**将"我的思考"部分融入正文（可润色，核心观点不可丢弃）
  - 引用格式：`作者等人 [论文简称] 指出…`
  - 可用表格、Mermaid 流程图等丰富呈现
  - 深度优先：回答须有原理、公式、代码示例、工程细节，不做表面罗列
  - 涉及具体工程实现须给出可查证的具体示例

### 第三步：追加日志
```
## [YYYY-MM-DD HH:MM] <专题名称> 综述
- **专题文件**: todo/<文件名>.md
- **正式笔记**: content/专业学习/<文件名>.md
- **参考文献**: N/A（综述任务）
- **关键词**: #tag1 #tag2
- **摘要**: 一句话说明综述覆盖范围与主要回答的问题
```

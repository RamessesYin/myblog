# 我的思考
当前的RL策略并不允许单次偏离模型太多，这可能是出于快速收敛以及防止训练的更差等考虑。但是也因此限制了模型本身的能力， 参考材料用pass@k的方法来进行评估，发现如果给基模更多的选择机会，他也能给出真正的答案，甚至如果给更多的选择机会，反而会比RL模型效果更好。 这说明RL并没有发展出超过基模边界的能力，只是更快的在可能的回答中搜索出正确的那个。

其实人也是一样，通常一次两次强化学习并不允许人类对自己的行为模式做出非常大的改变，但是持之以恒的影响会改变人的性格。另一方面，人是可能在一两次重大的变故中，突然改变自己的行为模式，当然这有可能是向好有可能是向坏，是否允许在模型中也加入这种随机因子，但是迅速掐灭偏离的非常厉害的？这跟基因突变一样，但是问题是可能需要非常久远之后才能发现到底合不合适，而不是在突变后的某一次回答中就干掉它。

除此之外，就是训练数据集到底怎么来了，纯语言模型无法很好处理各种信息输入、自己的输出也无法与客观世界形成比较好的交互。很多时候为了收敛，会让它充分学习某个领域特化。

# 我的思考

在特定模型（如Qwen2.5-Math）中，即便使用与 ground-truth 完全无关、甚至是随机或错误的奖励信号进行训练，模型在标准基准测试上的表现依然会出现大幅度的“虚假提升” 。

所谓“虚假奖励”（Spurious Rewards），特指上述分类中与任务逻辑真值解耦的信号，包括随机奖励、纯格式奖励以及反向的错误奖励 。悖论在于，经典的强化学习理论认为噪声奖励会引入大量随机性，从而抑制对最优行为的探索；但在RLVR环境下(Verifiable Rewards)，Qwen系列模型表现出了极强的“容错性”，甚至能在完全错误的引导下提高测试准确率 。   

在接受虚假奖励训练的模型中，研究者观察到了显著的指标背离：
1. 答案Token困惑度剧降：模型对最终答案Token的预测变得极其确定和自信，概率分布高度集中。    
2. 提示词/推理链困惑度上升：与此同时，模型对提示词的重构能力以及全局语言建模的连贯性却在退化，表明其语言建模的泛化性遭到了破坏。 

实际是模型在训练时就存在不同程度的数据泄露。模型所谓的进步，往往只是在更高效地检索训练集中的污染知识。模型牺牲了对输入问题的一般语言理解能力，换取了对特定答案的精准记忆。Qwen2.5-Math 在面对 MATH-500 等公开基准测试时，若仅给定题目开头 60% 的内容，其能够以 54.6% 的精确匹配率复现剩余的 40% 文本 。虚假奖励在 RLVR 训练中扮演了“激活剂”的角色，它并不提供知识，而是通过策略梯度的压力，迫使模型发现这条效率最高的“作弊”路径 。

论文在模型内部识别出了一个名为“锚点-适配器电路”的隐藏结构。在中间层的“功能锚点”处，模型通过特定的 MLP 神经元集群对输入信息进行匹配。研究发现，当模型检测到被污染的题目时，这些层会产生极强的“分离力”（Separation Force），将隐藏状态的轨迹从正常的推理路径推向特定的检索分支 。随后的“结构适配器”层虽然不存储具体答案，但它们在强化学习过程中经历了剧烈的权重调整，以适应并传播来自锚点层的突发检索信号 。
   
这种机制解释了为何即便奖励是错误的（如 Incorrect Reward），模型依然能提升性能。因为对于模型而言，从记忆中检索一个可能正确的答案，即便偶尔得到负反馈，其期望奖励仍可能高于在一个未知的推理路径上进行盲目探索。

论文dump logits，观测到了候选token到变化，亲眼见证了Lay24层硬生生要插入记忆答案的过程 。并且如果对这些神经元进行记忆抑制，虚假性能就会立即崩塌。

通过这种“因果操控”（Causal Steering），研究者成功将 Qwen 模型的性能解构为两部分：一部分是其真正的逻辑推理能力，另一部分则是通过 RLVR 训练被激活的、基于污染数据的虚假性能 。这种方法为后训练阶段的模型去污染（De-contamination）提供了一种全新的机械论视角，即我们可以通过关闭特定的神经元闸门，来剥离模型的作弊行为，而不损伤其通用能力。   



### 策略熵与裁剪偏差的理论驱动力

虚假奖励之所以能够奏效，除了模型内部的记忆结构外，还得益于 RLVR 特有的优化动力学。在 PPO 或 GRPO 等算法中，策略更新通常受到严格的裁剪（Clipping）限制，以防止策略发生灾难性的偏移 。   
研究指出，在虚假奖励的影响下，裁剪偏差（Clipping Bias）会导致一个名为“策略熵压缩”的效应：
- 抑制探索：由于随机或错误奖励无法提供连贯的学习信号，模型无法通过有效的探索来发现新策略。   
- 强化高先验：裁剪机制在处理高噪声奖励时，会下意识地偏向于加强模型初始分布中概率已经较高的路径。对于被污染的题目，其记忆路径的初始概率（先验）极高，因此在任何形式的 RLVR 迭代中，这些路径都会被不断加固 。   
这种熵减过程驱动模型变得更加“果断”且“确定”，从而在 Pass@1 指标上表现优异，但在衡量解空间广度的 Pass@k 指标上，RLVR 训练后的模型往往反而不如原始基准模型 。这揭示了当前 RLVR 实践中的一条“隐形锁链”：它往往只是在放大模型已知的答案，而非扩展其推理边界。
